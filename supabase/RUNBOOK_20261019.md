# Database runbook: debit notes + document number fix (2026-10-19 release)

Run each file in **Supabase Dashboard → SQL Editor**, one file per run, in this order.
Both are additive and safe to run more than once. Take a backup first
(Dashboard → Database → Backups).

| Order | File | What it does |
| --- | --- | --- |
| 1 | `migrations/20261019_01_document_number_padding.sql` | **Bug fix.** Invoice, quote, receipt, PO and RFQ numbers broke after the 99th document of a financial year (the 100th became `.../10`, a duplicate, and every later one failed). Numbers now grow past the padding (`.../99`, `.../100`). Numbers already issued are unchanged. |
| 2 | `migrations/20261019_02_debit_notes.sql` | Debit notes: the `debit_notes` table, its number series in Sales Settings (`SI/DN/25-26/01`), the functions that issue and cancel them, and a guard that freezes an invoice while it has debit notes. |

Run them before or together with the app deploy: the old app does not use these
objects, so running them first changes nothing for users. Until file 2 is applied,
**Sales → Debit Note** shows a message asking for it.

A `WARNING` is informational. Any `ERROR` means nothing in that file was applied:
stop and share the message.

## After running

1. **Admin → Settings → Sales → Debit Notes**: check the prefix (default `SI/DN`).
   GST allows at most 16 characters in a debit note number; the page warns if the
   prefix is too long.
2. Issue a test debit note: **Sales → Invoice**, the "Issue debit note" button (file with an
   up arrow) on an invoice row, or **Sales → Debit Note → New Debit Note**.
   - The number is the next in the series; the PDF says "Debit Note" and quotes the
     invoice number and date.
   - GST matches the invoice: CGST + SGST or IGST, none on a non-GST invoice.
   - Try to edit or cancel that invoice: it is refused until the debit note is cancelled.
3. As that customer, **Dashboard → Invoices** lists the debit note under "Debit Notes"
   (for an order's invoice, once the order is delivered).
4. Cancel the test debit note with a reason: it stays in the list as Cancelled and the
   customer no longer sees it.

## How each reason is charged

The form asks only for what changed; the amount and GST come from the invoice's own
lines (billed rate after discount, quantity, GST rate). A debit note carries only the
difference, never the whole invoice again.

| Reason | You enter | Charged |
| --- | --- | --- |
| Price revised upward | New rate per item | (new rate − billed rate) × qty, + GST at the invoice's rate |
| Quantity under-billed | Extra units supplied | extra units × rate, + GST at the invoice's rate |
| Additional charges | Each charge (freight, packing…) | the amount, + GST at the goods' rate (composite supply), changeable |
| GST charged too low | Correct GST rate per item | only the missing tax: taxable value 0, e.g. 12% → 18% on ₹1,000 = ₹60 |
| Other | Free lines | as entered |

A short supply (fewer goods than billed) is a credit note, not a debit note.

## Debit notes in brief (GST)

- Issued by us to a customer when an invoice charged **less** than was due: price revised
  upward, quantity short-billed, extra charges (freight, packing), or GST charged at too
  low a rate (CGST Act s.34(3)). A credit note is the opposite (charged too much).
- Rule 53(1A): number up to 16 characters (letters, digits, `-`, `/`), unique in the
  financial year; must show the original invoice's number and date, the taxable value,
  GST rate and amount, and a signature. Our PDF uses the invoice template with these.
- Reported in **GSTR-1 for the month it is issued** (table 9B) and the extra tax paid in
  that month's GSTR-3B. There is no deadline to issue one, but it can't be dated before
  the invoice.
- If turnover crosses the e-invoicing limit (₹5 crore), debit notes need an IRN too
  (document type DBN). Not built yet.
- Cancel, never delete: a cancelled number is never reused.

## Not included yet

- **Payments against a debit note.** The invoice balance in Payments Received does not
  include debit notes yet. Until it does, record the money as an "Other" allocation with
  the debit note number in the note.
- E-invoice (IRN) and GSTR-1 export.

## Rolling back

Debit notes are immutable records, so there is no automatic rollback once any is issued.
Before any is issued, it is safe to leave the objects in place for an older app version
(it doesn't use them). The number fix (file 1) should not be rolled back.
